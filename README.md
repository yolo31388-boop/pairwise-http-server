# 游戏内HTTP服务器与远程管理系统

## 项目描述

游戏内HTTP服务器与远程管理系统的bug修复项目。核心模块 `http/server.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 服务器启动只绑定localhost外部访问不了
- 路由完全没做所有请求返回404
- WebSocket完全没做连接后直接断开
- 认证完全没做谁都能调用管理接口
- 限流完全没做玩家可无限调用API

## 运行测试

```bash
python -m pytest tests/test_server.py -q
```

修复目标：所有 16 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
